# Профиль системы агентов (для сравнения с другими)

Состояние на 2026-11-07. Репозиторий `asilios/seo-agents`. Первый клиент — forma-3d.uz (интернет-магазин филамента и запчастей Bambu Lab, Ташкент, ru + uz-Latn).

## 1. Что это

Набор агентов на Claude Code. **Оркестратор** (главная сессия) по расписанию запускает субагентов, сам вносит правки в код сайта, проверяет их, выкладывает и пишет отчёт владельцу.

- **Цель:** первая страница / топ Google по запросам клиента.
- **Успех меряется:** позициями, показами и кликами. Количество закрытых пунктов аудита — не метрика.
- **Модули:**
  - SEO — работает;
  - GEO (видимость в ответах ChatGPT, Perplexity, Gemini, Claude) — Фазы 1–2: вопросы утверждены, монитор написан, регулярных замеров пока нет;
  - соцсети — на паузе.

## 2. Состав

| Роль | Тип | Что делает | Как часто |
|---|---|---|---|
| Оркестратор | главная сессия | запускает цикл, анализирует, правит код сайта, проверяет, сливает, отчитывается | еженедельно (облачная задача, пн 09:00 Ташкент) + по запросу в чате |
| `auditor` | субагент | краул сайта, коды ответов, H1/title/description, canonical, hreflang, schema, кириллица на /uz | еженедельно |
| `keyword-strategist` | субагент | семантика, кластеры, конкуренты | ежемесячно |
| `onpage-optimizer` | субагент | правки title/description/H1/alt/перелинковки/schema → `changes/pending/` | после аудита |
| `content-writer` | субагент | статьи и посадочные тексты ru + uz | ежемесячно |
| `reporter` | субагент | ежемесячный отчёт против базовой точки | ежемесячно |
| `geo-query-mapper` | субагент | 30–100 вопросов к ИИ по нише | раз в квартал |
| срез выдачи | субагент общего назначения + Firecrawl | позиции по 12–15 главным запросам (Google, Узбекистан, топ-30) | еженедельно |

**Скрипты:**
- общие: `crawl.py`, `gsc.py` (Search Console), `check_paths.py`;
- SEO: `pagespeed.py`;
- GEO: `geo_monitor.py`, `geo_providers.py`, `geo_parse.py`, `validate_geo.py`.

**Команды:** `/new-client`, `/weekly`, `/monthly`, `/approve`, `/geo-map`.

## 3. Как работает недельный цикл

1. **Синхронизация:** `git pull`, чтение `NEXT.md`, журнала и последнего аудита.
2. **Замер:**
   - срез выдачи;
   - аудит;
   - Search Console — только если есть ключ. В облаке ключа нет.
3. **Анализ:** ранжирование гипотез по формуле (прирост × уверенность) / трудозатраты. В первую очередь — запросы на позициях 8–30 и коммерческие страницы.
4. **Действие:** 1–3 изменения за запуск, не больше, чтобы было понятно, что дало эффект.
5. **Публикация** (разрешено владельцем 2026-11-02):
   - ветка `seo-auto-ДАТА` → `typecheck` → `build` → локальный запуск;
   - проверка всех URL из sitemap: код 200, один H1, title ≤60, description ≤160, нет кириллицы на /uz, нет «[УТОЧНИТЬ»;
   - пересборка архива для Railway → слияние в `main` → проверка живого сайта;
   - сломалось — `git revert`.
6. **Отчёт владельцу** простым языком, журнал, `NEXT.md`, коммит и push.

## 4. Жёсткие ограничения (что агент сам НЕ делает)

- **Не публикует без владельца:** цены, наличие, сроки доставки, гарантии, скидки, контакты, новые обещания, удаление разделов, редизайн.
- **Не выдумывает цифры:** только из краула, выдачи, GSC и ответов скриптов. Нет данных — так и пишет.
- **Не трогает** `baseline.md`.
- **Ничего не отправляет наружу:** заявки, письма, отзывы только черновиками в очередь, отправляет владелец (GEO).
- **Ключи** только в `.env` и секретах. В чат не просит.
- **Ошибка или пустой результат субагента** — цикл останавливается.

## 6. Слабые места (честно)

- **Нет частотности.** Ядро — экспертная оценка: Wordstat и Keyword Planner не подключены.
- **В облаке нет ключей GSC и PageSpeed.** Показы и клики видны только при запуске в чате на рабочем компьютере. Пока их 0: сайт молодой.
- **Позиции из Firecrawl приблизительные:** датацентр, без персонализации. Сдвиг на 1–2 места — шум.
- **Зависимость от сетевого доступа облака.** 02.11 и 06.11 сайт был закрыт прокси, и аудит с выкладкой пропускались.
- **Внешние факторы (ссылки, карты, отзывы)** агент не делает. Только черновики и просьбы владельцу.
- **Главный блокер роста — цены.** У большинства товаров нет реальной цены. Решение за владельцем, прайс ещё не получен.
- **Один клиент.** На других нишах система пока не проверялась, хотя GEO-модуль спроектирован как универсальный.
