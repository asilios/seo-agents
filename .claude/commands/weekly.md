description: Еженедельный цикл — аудит и on-page правки
argument-hint: <client-name | all>

Еженедельный цикл для `$ARGUMENTS`.
Если `all` — по очереди для каждой папки в `clients/`, кроме служебных (имя начинается с `_`: `_template`, `_demo-*`).

Для каждого клиента:
1. Субагент `auditor`.
2. Если аудит прошёл успешно — субагент `onpage-optimizer`.
3. Строки в `clients/<client>/seo/log.md`.

Итог по каждому клиенту: новых проблем, закрытых проблем, правок в `clients/<client>/seo/changes/pending/`.
При ошибке у клиента — остановить его цикл, сообщить и перейти к следующему.
