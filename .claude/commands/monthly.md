Ежемесячный цикл для `$ARGUMENTS`.
Если `all` — по очереди для каждой папки в `clients/`, кроме `_template`.

Для каждого клиента:
1. Субагент `keyword-strategist`.
2. Субагент `content-writer` (количество материалов — `content_per_month` из client.yaml, по умолчанию 2).
3. Субагент `reporter`.
4. Строки в `log.md`.

Итог: путь к отчёту, сколько материалов написано, сколько правок ждёт одобрения.
