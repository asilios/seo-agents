# Семантическое ядро — Форма-3D (forma-3d.uz)

Версия: 2026-10-29 (первое ядро, подключение клиента). Предыдущей версии нет, резервная копия не создавалась.

## Источники и ограничения

- **GSC: данных нет.** `gsc_site` в client.yaml пустой, выгрузки `data/gsc-*.csv` нет. Поэтому показов и позиций в этом файле нет, и раздел «Быстрые победы» пустой.
- **Частотность неизвестна для всех запросов.** Сервиса частотности (Wordstat, Keyword Planner и т.п.) нет. Ни одной цифры объёма в файле нет.
- **Приоритет 1–3 — экспертная оценка стратега, а не цифра.** Учитывалось: насколько запрос коммерческий, есть ли товар в наличии и с ценой, есть ли уже страница, есть ли такая страница у конкурентов, совпадение с USP.
- Список страниц сайта взят из `data/crawl-2026-10-29.json` (251 URL, 108 товаров × ru/uz). Проблемы сайта — из `audits/2026-10-29.md`.
- Конкуренты: главные страницы и разделы смотрел через WebFetch 2026-10-29. Позиции конкурентов в выдаче неизвестны (данных SERP нет).
- Запросы ниже — гипотезы. Они составлены по ассортименту, по словам, которые сайт и конкуренты уже используют, и по типичному написанию в Узбекистане. Это не выгрузка из инструмента.

## Как читать кластеры

- Сайт двуязычный: у каждой страницы есть пара `/ru/...` ↔ `/uz/...` (hreflang настроен). Поэтому **один кластер = одна пара страниц ru/uz с одинаковым slug**. Запросы разделены по языкам. Целевые URL указаны для обоих языков.
- Узбекская версия сайта на латинице (uz-Latn). Пользователи пишут и кириллицей: «филамент нархи», «3д принтер учун пластик». Кириллической версии нет, поэтому такие запросы не берём в цель отдельно. Их можно ловить, если в uz-Latn-текст естественно вставить ключевые латинские формы с брендом и моделями (Bambu Lab, A1, PLA и т.п. пишутся одинаково).
- Варианты написания (транслит, ошибки) указаны в запросах: «бамбу лаб», «bambulab», «петг/пэтг», «хотенд», «пла пластик».

## Блокеры (из аудита), без которых коммерческие кластеры не заработают

1. Надпись «Демонстрационная версия. Цены и остатки — примеры» (demo-notice-001).
2. У 200 из 216 карточек нет цены и Offer в разметке (no-offer-001). Запросы «… цена / narxi» на карточку с «Цена по запросу» вести бесполезно.
3. Нет контактов (contacts-001). Локальные запросы «… Ташкент» без адреса, телефона и Telegram слабые.
4. Одинаковые H1 и title у цветов и у пар катушка/рефилл (dup-h1-001, dup-product-001). Из-за этого карточки конкурируют между собой за одни и те же запросы.

## Важное о структуре сайта

Есть только два листинга: `/catalog` (весь филамент, 4 страницы пагинации) и `/catalog/parts` (запчасти, 3 страницы). **Отдельных страниц по материалам (PLA, PETG, ABS…), по типам запчастей (хотэнды, столы, AMS) и по моделям принтеров нет.** В подвале есть пункты «PLA» и «PETG», но краулер не нашёл для них отдельных URL. Нужно проверить, куда они ведут (вероятно, на фильтр без своего адреса).
Поэтому многие кластеры ниже требуют новых посадочных страниц-категорий. Это задача для разработчика и для content-writer, а не только для текстов.

`/ru/knowledge` — это 5 заголовков статей без текста и без ссылок (проверено WebFetch). Фактически статей на сайте нет.
